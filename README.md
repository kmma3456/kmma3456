# Hello, World! 👋

안녕하세요.  
한국에서 활동하고 있는 풀스택 개발자 오영균입니다.

TypeScript를 중심으로 프론트엔드, 백엔드, API, 데이터 처리, 서비스 운영 및 유지보수까지 웹 서비스 전반을 직접 설계하고 개발해왔습니다.

단순히 기능을 구현하는 것보다 실제 업무를 더 효율적으로 만들고, 반복 작업을 줄이며, 운영하기 편한 시스템을 만드는 개발에 관심이 많습니다.

최근에는 AI를 개발 워크플로우에 적극적으로 활용하고 있습니다.

Cursor 및 AI Agent를 이용해 코드 작성, 리팩토링, 디버깅, 구조 설계, 문서화 등 개발 전반의 생산성을 높이고 있으며, 
프로젝트에서는 LLM API 연동, 프롬프트 설계, 응답 처리, 서비스 기능 연계 등 LLM을 실제 웹 서비스 기능으로 구현해본 경험도 가지고 있습니다.

웹 개발뿐 아니라 자동화 프로그램, ERP, MES, 플랫폼 및 쇼핑몰 등 다양한 형태의 실무 프로젝트를 경험해왔습니다.

## Tech Stack

JavaScript, TypeScript, React, Node.js, Next.js, PHP, Laravel, Python

## AI & Development Tools

Cursor, AI Agent, LLM API Integration, Prompt Engineering, AI-assisted Coding, AI 기반 코드 리팩토링 및 디버깅, 반복 업무 자동화

AI를 단순 코드 생성 도구로 사용하는 것이 아니라 개발 속도와 품질을 높이기 위한 실무 도구로 활용하는 데 익숙합니다.
