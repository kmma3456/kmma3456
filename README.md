안녕하세요. 한국에서 활동하고 있는 풀스택 개발자 오영균입니다.

TypeScript를 기반으로 웹 서비스 개발을 주로 진행하고 있으며,
프론트엔드부터 백엔드, API 개발, 서비스 운영 및 유지보수까지
웹 개발 전반의 업무를 경험하고 있습니다.

최근에는 AI를 개발 과정에 적극적으로 활용하고 있습니다.
Cursor와 같은 AI 기반 개발 도구 및 AI Agent를 활용하여
코드 작성, 리팩토링, 디버깅, 구조 설계 등 개발 생산성을 높이고 있으며,
단순한 코드 생성이 아닌 실제 서비스 개발 과정에서 AI를 효과적으로 활용하는 데 익숙합니다.

또한 Yacht 프로젝트를 통해 LLM을 활용한 기능 개발 경험이 있으며,
LLM API 연동, 프롬프트 설계, 응답 처리 및 서비스 기능과의 연계 등
AI 기능을 실제 웹 서비스에 적용해 본 경험이 있습니다.

새로운 기술을 빠르게 학습하고,
기존 웹 개발 기술과 AI를 결합하여 더 효율적인 서비스를 만드는 것에 관심이 많습니다.
